## 👋 About

Frontend engineer and **founding team member** at an early-stage SaaS startup for small-business owners. I build **end-to-end** — not isolated UI — from payments and auth to native app behavior, and I care most about the parts that quietly break: session edge cases, payment state, and keeping an architecture coherent as it grows.

- 🧩 Web (React) + iOS/Android (Capacitor) from **one codebase**
- 💳 Owned **subscription & billing** end-to-end — Toss Payments & in-app purchase (renew / cancel / expiry)
- 🔐 Built **authentication** — JWT access/refresh + social OAuth (Kakao / Naver / Google)
- 🏗️ Drove a **1.5-year frontend architecture convergence** to keep the codebase maintainable as it scaled
- 🎓 B.S. Computer Science · major GPA **4.35 / 4.5** · a semester abroad on exchange
